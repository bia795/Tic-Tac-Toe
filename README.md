Este projeto é uma recriação do clássico Jogo da Velha, desenvolvido no Visual Studio 2022.

Tecnologias e Aprendizados:
Buttons para criar a interface interativa.
Estruturas condicionais (if) para controlar jogadas e verificar vitória/empate.
Variáveis boolean para gerenciar o estado do jogo.

Objetivo: Treinar lógica de programação e manipulação de elementos gráficos, aplicando boas práticas de desenvolvimento.

Resultado: Um jogo funcional, simples e intuitivo, que reforça a importância de dominar a base da programação antes de avançar para projetos mais complexos.
